## AI Builder Platforms

Detects sites generated by vibe-coding / AI builder platforms. Full fingerprint analysis (including detectability assessment per platform) lives in [ai-builder-fingerprints.md](ai-builder-fingerprints.md).

| Pattern | Indicates | Confidence |
|---------|-----------|:---:|
| `/lovable-uploads/` path in link/img/script src | Lovable | **Very High** |
| `data-dpl-id` attribute on `<html>` | Lovable | **High** |
| `meta name="author" content="lovable"` | Lovable | Medium |
| `vusercontent.net` in script/src | v0 by Vercel | Medium |
| `X-Powered-By: Hostinger Horizons` | Hostinger Horizons (AI builder) | **High** |
| `gamma_visitor_id` cookie / `gammaSiteAnimationsInitialized` | Gamma | **High** |
| `cdn.durable.co` script src | Durable | **High** |
| `app.zipwp.com` script src | ZipWP (AI WordPress builder) | **High** |

> **Note**: v0, Bolt.new, Cursor, Windsurf, and Claude Code are effectively undetectable on custom domains — they produce standard code with no fingerprint. Only default subdomains (`*.v0.app`, `*.bolt.new`) are reliable signals. See [ai-builder-fingerprints.md](ai-builder-fingerprints.md) for the full assessment.

## Meta Tag Detection

| Meta Tag | Indicates |
|----------|-----------|
| `<meta name="generator" content="...">` | CMS identifier (WordPress, Drupal, Joomla) |
| `<meta name="csrf-param"` / `<meta name="csrf-token"` | Rails / Laravel / security framework |
| `<meta property="og:site_name"` | Open Graph (SEO framework present) |
| `<meta name="theme-color"` | PWA-capable framework |
| `<meta name="apple-mobile-web-app-capable" content="yes">` | PWA enabled |
| `<meta name="robots" content="noindex">` | SEO directive |
| `<link rel="manifest" href="...">` | PWA manifest present |
| `<link rel="alternate" hreflang="...">` | Multi-language site |
